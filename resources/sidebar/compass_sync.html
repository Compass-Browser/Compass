The address of the Compass sync server you run, or one you trust. Every device of a chain uses the same one.

Your recovery code

Save these 12 words somewhere safe, such as a password manager. You only need them if you lose every device that syncs: without them, the synced data is gone.

      What syncs

        Recovery code

        The 12 words that bring your data back if you lose every device. Compass asks for Touch ID or your password first.

        Server

        To use another server, leave sync and join again with the new one.

        Leave or reset

        Leaving keeps this device's data and stops syncing it. Resetting makes a new chain with a new recovery code: this device's data goes up again, and your other devices must join again.
