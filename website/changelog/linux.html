What's new on Linux

MacWindowsLinuxiPhone and iPad

Compass for Linux is a canary for now: new builds come often, for testing. Installed with Flatpak from the homepage, it updates with flatpak update or your software center; a tarball doesn't update itself. Every release is on GitHub.

20261114.1010 Canary

14 November 2026 · Chromium 157.0.8103.51

  • Little windows. A link from another app opens in a little window instead of a new tab, and Shift+Alt+N opens a new one; on X11 the shortcut works from any app.
  • The Shortcuts page lists all of Compass's keyboard shortcuts, not only the spaces', and lets you change them.
  • Compass's own shortcuts on Linux: Ctrl+Shift+C copies the page's link, Ctrl+S shows or hides the sidebar, Ctrl+Shift+M mutes the tab and Ctrl+Shift+E opens Claude's chat.
  • Claude through a gateway that adds cache markers of its own works too: Compass steps down until the request goes through and remembers it.

20261114.0019 Canary

14 November 2026 · Chromium 157.0.8103.51

  • Updates through Flatpak. Install Compass from the homepage with Flatpak and it updates with the rest of your apps.
  • Spaces that don't sync: in a space's menu, turn off "Sync to your other devices" to keep it, and its tabs, on this computer only, or make one with "New space on this device" in the command bar. A dot on the space's button in the switcher marks it.
  • Claude's developer tools (Settings → Claude, off by default): Claude can look at a page's network requests, elements and styles, storage and performance, and emulate devices and slow networks. Changes to cookies or storage ask you first.
  • Claude and files: Claude can save files, or read and write them in a folder you choose, asking before each save or change.
  • Claude through a gateway or custom endpoint no longer fails with "A maximum of 4 blocks with cache_control".
  • Undocked developer tools open as a window only, not as a tab in the space.
  • Picture in picture: the controls at the bottom stay inside the window on videos with no next track, such as YouTube's.
  • Larger icons on the Pinned and Today headers.

20261112.2020 Canary

12 November 2026 · Chromium 157.0.8103.51

  • A model menu in the Claude chat's header: pick another model and the conversation goes on with it.

  • Compass's logo in place of Chrome's in Settings, Safety Hub and the certificate manager, and no more gap where its ribbons cross.

20261111.1914 Canary

11 November 2026 · Chromium 157.0.8103.51

  • Chromium 157.
  • Claude memory. Claude can save short facts about you (preferences, what you work on) and uses them in later chats. Each save shows in the chat with Undo, and Settings lists them to edit, delete or add, with switches to turn memory or saving off. Memories sync with your other devices.
  • Live folder plugins of your own: put them in the Compass Plugins folder (Open Plugins Folder takes you there).
  • New Live Folder has its own icon, a folder with a bolt, beside New Folder.

20261110.0949 Beta

10 November 2026 · Chromium 156.0.8078.48

  • The first beta of Compass for Linux (x64), with the same features as Compass for Windows 20261110.0937.
  • Two ways to install it: a tarball (unpack it and run ./compass; the README inside explains the sandbox helper and adding a menu entry), or a Flatpak (flatpak install --user the file; it needs the Freedesktop 25.08 runtime and the Chromium BaseApp from Flathub).
