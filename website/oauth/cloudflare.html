Sign in with Cloudflare from Compass

This step only works when Compass starts it. Compass sets up your own sync server in your Cloudflare account: it opens Cloudflare's sign-in in a tab, and when you allow it, Compass picks up the answer and closes the tab by itself, before this page shows.

If you see this page, the sign-in didn't start from Compass, or it ran in another browser. Nothing was set up.

To set up your server

  1. Open Compass, then Settings, then Sync.
  2. Choose No server? Set up a free one on Cloudflare.
  3. Choose Sign in with Cloudflare, and allow Compass on the page that opens.

The answer Cloudflare sent here is useless on its own: only the copy of Compass that started the sign-in can use it, and it does so once, to set up the server. Compass doesn't keep access to your Cloudflare account.
