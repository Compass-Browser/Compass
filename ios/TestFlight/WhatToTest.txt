Claude can now save and edit files, with your OK each time, and auto picture in picture works on YouTube.

- Settings → Claude → Files: choose Save Files (new files go to Compass's Downloads folder, in the Files app) or Use a Folder (pick a folder; Claude can list, read and write files in it, and nowhere else). Off by default.
- Ask Claude for a file ("save these notes as a file", "fix the typos in notes.md"). Before each save or change a card shows what it will write: Allow, Allow for This Chat, or Deny.
- YouTube: play a video with sound, then switch tab or scroll it off screen; it should keep playing in a picture-in-picture window.
- If auto picture in picture doesn't start, Settings → Auto Picture in Picture → Copy Diagnostics, and paste it in your report.
- Please also report: a folder that's forgotten after relaunching Compass, files in the wrong place, or a card that doesn't go away.
