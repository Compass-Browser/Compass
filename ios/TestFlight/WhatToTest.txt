Actions in the command bar, and a better Claude chat.

- Command bar actions: type an action's name, like "settings", "reader", "copy link" or "reopen", and it comes first; Return runs it. Part of a name ("sett") lists it at the bottom, under Commands. Actions: Find on Page, Reload, Copy Link, Reader, Pin or Unpin Tab, Development Mode, Tidy Today, Chat with Claude, New Incognito Tab, Reopen Closed Tab, Downloads, Settings.
- Claude chat: replies show headings, lists, code blocks, quotes and tables; links open in a new tab. You can write while Claude replies: your messages wait above the field and go one after another.
- Sign in with Google (and other popups that report back to the page) now works in every tab.
- Development mode starts on for localhost.
- Spaces joined on the Mac while an older version was installed now show up after updating.
- Please report: an action that does nothing or the wrong thing, an action missing when it should show, Return searching when an action is first, and chat replies that look wrong.
