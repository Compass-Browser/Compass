Compass uses Chrome's shortcuts, with a few changes borrowed from Arc. The
table lists the ones that are Compass's own or that work differently from
Chrome, plus the most common ones. Everything else works as in Chrome.

## Compass

| Action | Mac | Windows and Linux |
|---|---|---|
| New tab (opens the command bar) | <kbd>⌘</kbd> <kbd>T</kbd> | <kbd>Ctrl</kbd>+<kbd>T</kbd> |
| Edit the page's address (command bar) | <kbd>⌘</kbd> <kbd>L</kbd> | <kbd>Ctrl</kbd>+<kbd>L</kbd> |
| Show or hide the sidebar | <kbd>⌘</kbd> <kbd>S</kbd> | <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| Copy the page's link | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>C</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> |
| New [little window](/guide/little-window/), from any app | <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>N</kbd> | <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> |
| Chat with [Claude](/guide/claude/) | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>E</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> |
| [Reader mode](/guide/reader-mode/) | <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>R</kbd> | <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd> |
| Let clicks through [picture-in-picture](/guide/picture-in-picture/), from any app | <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>P</kbd> | <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> (Windows only) |
| Switch to space 1 to 9 | <kbd>⌃</kbd> <kbd>1</kbd> … <kbd>⌃</kbd> <kbd>9</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>1</kbd> … <kbd>9</kbd> |

| Keep a Peek or little window's page as a tab | <kbd>⌘</kbd> <kbd>O</kbd> | <kbd>Ctrl</kbd>+<kbd>O</kbd> |

## What changed from Chrome

A few keys do something else in Compass than in Chrome:

- <kbd>⌘</kbd> <kbd>S</kbd> / <kbd>Ctrl</kbd>+<kbd>S</kbd> shows or hides
  the sidebar. **Save Page As** is still in the menus, without a
  shortcut.
- <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>C</kbd> /
  <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> copies the page's link,
  without tracking parameters (unless you turn that off in Settings).
  Inspect element is still <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>C</kbd> on a Mac,
  and <kbd>F12</kbd> or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> on
  Windows and Linux.
- <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>N</kbd> /
  <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> opens a little window
  instead of a new split tab.
- <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>M</kbd> /
  <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> mutes the tab instead of
  opening the profile menu.
- <kbd>⌥</kbd>-click / <kbd>Alt</kbd>+click on a link peeks at it instead
  of downloading it.
- On a Mac, <kbd>⌘</kbd> <kbd>Z</kbd> brings back the tab you just closed,
  as long as you're not typing and the page doesn't use the key itself.

## Change a shortcut

On a Mac, Windows or Linux computer, go to **Settings** > **Keyboard
shortcuts**, or type "Keyboard shortcuts" in the command bar. The page
lists the shortcuts you can change, in sections: Compass, Tabs, Windows,
Browser, Developer and Spaces.

1. Click a shortcut's keys.
2. Press the keys you want. They need at least one of <kbd>⌘</kbd>,
   <kbd>⌃</kbd> or <kbd>⌥</kbd> on a Mac, or <kbd>Ctrl</kbd> or
   <kbd>Alt</kbd> on Windows and Linux.
   - <kbd>Esc</kbd> cancels.
   - <kbd>Delete</kbd> leaves the action without a shortcut.
3. If another shortcut already uses those keys, Compass asks whether to
   move them to this one.

A changed shortcut shows its default and a **Reset** button. **Reset all**
undoes every change.

Some keys can't be taken, such as Quit, Close Tab, Close Window, and copy
and paste: Compass tells you what already uses them. Extensions' shortcuts
are set on Chrome's extension shortcuts page, not here.

## iPad and iPhone with a keyboard

With a hardware keyboard, hold <kbd>⌘</kbd> to see the list on iPad.

| Action | Keys |
|---|---|
| New tab (command bar) | <kbd>⌘</kbd> <kbd>T</kbd> |
| Edit the address | <kbd>⌘</kbd> <kbd>L</kbd> |
| Show or hide the sidebar | <kbd>⌘</kbd> <kbd>S</kbd> |
| Reload | <kbd>⌘</kbd> <kbd>R</kbd> |
| Reload without the cache | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>R</kbd> |
| Back / Forward | <kbd>⌘</kbd> <kbd>[</kbd> / <kbd>⌘</kbd> <kbd>]</kbd> |
| Copy the page's link | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>C</kbd> |
| Find on page | <kbd>⌘</kbd> <kbd>F</kbd> |
| Next / previous tab | <kbd>⌃</kbd> <kbd>Tab</kbd> / <kbd>⌃</kbd> <kbd>⇧</kbd> <kbd>Tab</kbd> |
| Close the tab | <kbd>⌘</kbd> <kbd>W</kbd> |
| Switch to space 1 to 9 | <kbd>⌃</kbd> <kbd>1</kbd> … <kbd>⌃</kbd> <kbd>9</kbd> |
| New window | <kbd>⌘</kbd> <kbd>N</kbd> |
| New incognito tab | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>N</kbd> |
| Reopen a closed tab | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>T</kbd> |
| Reader mode | <kbd>⌘</kbd> <kbd>⌥</kbd> <kbd>R</kbd> |
| Chat with Claude | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>E</kbd> |

In Peek and little windows, <kbd>⌘</kbd> <kbd>O</kbd> keeps the page and
<kbd>⌘</kbd> <kbd>W</kbd> closes it.
